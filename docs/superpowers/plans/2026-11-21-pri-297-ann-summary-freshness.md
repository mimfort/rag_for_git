# PRI-297. План согласования свежести сводок

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans. Check each step against its acceptance criteria.

**Goal:** Согласовать свежесть сводок в ANN и полной выдаче, затем проверить эффект для solve-task на живом индексе.

**Architecture:** Общее сравнение с кэшируемым снимком хешей в MCP-сервисе. Адаптер solve-task фильтрует подтверждённо устаревшие тексты.

**Tech Stack:** Python, pytest, ParadeDB, Voyage.

**Spec:** `docs/superpowers/specs/2026-11-21-pri-297-ann-summary-freshness-design.md`

## Global Constraints

- Порог ANN и размер top-k сохраняются. Миграция, переиндексация и перестройка сводок для замера не требуются.
- Модульные тесты работают без сети. Живой повтор читает неизменный индекс.

## Review Focus

- Нет записи метаданных при доступном индексе. Снимок используется в текущем ответе.
- Версия индекса или layout меняются. Следующий ответ проверяет новый снимок.
- Метаданные меняются во время чтения. Ответ сообщает неизвестную свежесть.
- Каталог сводок и источник хешей отказали независимо. Диагностика отражает доступные факты.
- ANN не вернул свежего кандидата при существующей сводке вне top-k. Диагностика различает отсутствие строки и отсутствие результата.
