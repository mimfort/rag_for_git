## Task 1: `python_skeleton` в `chunker.py`

### Что сделано
Добавлена функция `python_skeleton(source: bytes) -> list[int]` в `/reviewer/index/chunker.py` после `chunk_python`.
Обходит AST через tree-sitter (`_PARSER`), собирает 1-based номера строк:
- декораторы + многострочные сигнатуры def/class (включительно до `:`),
- первую строку docstring каждого определения,
- первую строку модульного docstring.
Не падает на битом коде. Возвращает `[]` если определений нет.

### Тесты добавлены (`tests/index/test_chunker.py`)
- `test_skeleton_includes_signatures_and_docstrings_not_bodies` — заголовки/docstring включены, тела исключены, только 1-я строка модульного docstring
- `test_skeleton_empty_for_source_without_definitions` — пустой список без def/class
- `test_skeleton_does_not_crash_on_syntax_error` — возвращает list при битом коде

### Прогон тестов

```

### Коммит
```
