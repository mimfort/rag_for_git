# PRI-295. Исключение текущей карточки из похожих задач

Источник требований — [бриф PRI-295](../briefs/2026-11-21-PRI-295-exclude-current-task.md).

## Поведение

`prepare_task_context` исключает найденную текущую карточку из `related.similar` и из поиска путей `similar-diffs`. Идентификатор карточки образуют её канонический ключ и все алиасы из стора. Хит исключается, если его ключ или алиас совпадает с одним из этих идентификаторов. При отсутствии карточки свободный текст используется для прежнего поиска.

Оставшиеся хиты сохраняют порядок и оценки. Рендер показывает до восьми результатов, включая следующий доступный хит. Выдача без хитов и недоступный поиск сохраняют свои сообщения. Вариант replay `similar_paths` использует идентификаторы той же разрешённой карточки при сборе путей. Публичный `search_tasks` продолжает самостоятельно искать задачи по тексту.

## Подход

`build_task_context` передаёт уже прочитанную карточку в `_TaskContextDeps.similar`. Сборщик фильтрует структурированные хиты до сохранения для `similar-diffs` и до рендера. `search_hits` уже возвращает пул до 30 хитов за один вызов.

Исключение в SQL до RRF могло бы изменить оценки остальных хитов и расширило бы контракт хранилища. Фильтрация видимых строк теряла бы восьмой результат и оставляла бы отдельный маршрут к diff-путям.

## Проверка

Регрессия покрывает вход по каноническому ключу и алиасу, пополнение выдачи, сохранение порядка, единственный поиск и отсутствие собственных путей в `similar-diffs`. При сравнении до и после используются одни и те же сырые хиты по восьми карточкам из исходной проверки. Сравнение фиксирует изменения состава выдачи.
