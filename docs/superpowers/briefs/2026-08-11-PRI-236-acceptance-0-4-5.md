## Constraints / open questions
- **Критерий 1 не выполним как написан: у CLI нет опции `--version`.** `reviewer --help` показывает только `--help` и список команд. Фактическая установка — `uv tool list` → `rag-reviewer v0.4.5` (`reviewer`, `reviewer-mcp`); `pyproject.toml:3` = `0.4.5`; кеш плагина — `.../rag-reviewer/0.4.5/`. Нужно решение: либо переформулировать критерий на `uv tool list` / `pip show rag-reviewer`, либо завести отдельную задачу на `reviewer --version` (не расширять скоуп приёмки молча).
- **Расхождение help-текста и реализации.** `cli.py:220-222` (help опции `--path`) обещает «по умолчанию — путь из индекса, затем текущий каталог», но `_resolve_clone_path` (`cli.py:196-207`) индекс намеренно не читает и его докстринг это фиксирует. Кандидат в находки приёмки — правка help-строки; поведение при этом корректно.
- Индекс на момент сбора брифа переиндексирован: `drift=0`, 452 файла @ `5bf5728`, граф SCIP (6682 узла, 32364 ребра), сводок 40 — то есть шаг 3 приёмки на ветке `dev` фактически уже выполнен в preflight и строка `repo_clone` записана.
- `sync_board` в preflight отработал инкрементально: enumerated 93, changed 0, failed 0, warnings пусты — критерий 5 в части `sync_board` предварительно подтверждён; `finish_task` не проверялся.
- Шаг 1 («выполнить `reviewer update`, перезапустить окно Claude Code») невыполним изнутри этой сессии — требует действий пользователя.
- Шаг 6 требует живого PR-кандидата: конкретный PR для полного цикла ревью не выбран.
- Критерий 3 не задаёт `N` для `limit` и порог «примерно 10 КБ» — договориться о конкретных значениях до прогона.
- Приёмка `config show` требует ветку с коммиченным `.review.yml`; ненулевой код возврата при непустом `skipped` — ожидаемое поведение PRI-234, не провал.
