# Brief — PRI-265 Эвал-харнесс молча теряет свидетельства: перезапись отчёта и неотличимый сбой обхода
https://ru.yougile.com/team/686c049c8af8/#PRI-265

## Task
Два независимых места, где офлайн-харнесс `eval/solve_task_metrics` теряет правду молча.
1. **Перезапись накопленного разбора.** `cmd_replay` пишет `eval/replay_report.md` целиком через `replay_report.render(...)`; ручные разделы приёмок частью render не являются и уничтожаются любым прогоном (измерено 2026-08-20 на приёмке PRI-262: удалено 745 строк, замечено случайно по `git diff --stat`).
2. **Сбой обхода неотличим от честно пустого ядра.** `except Exception → core_now = set()` даёт `context_status = empty_context_denominator` — тот же статус, что у задачи с законно пустым знаменателем (после PRI-262 таких 16 из 63), поэтому недоступный Neo4j или регресс обхода утонут в штатном шуме.

Что сделать (из тикета): маркер границы генерируемой/ручной части + перенос ручных разделов дословно; тест на побайтовую сохранность; отдельный статус `context_retrieval_failed` по образцу `STATUS_RETRIEVAL_FAILED`; отражение статуса в разделе «Статусы задач» и в агрегате (сбой ≠ пустой знаменатель); проверить, не повторяется ли смешение в `solve_task_metrics_report.md`.

Критерии приёмки: (1) прогон не теряет ни строки ручных разделов, закреплено тестом; (2) сбой обхода даёт отличимый статус, закреплено тестом с падающим `traverse`; (3) ни одно существующее число агрегата не меняется (аддитивность), проверено свойством на случайных входах; (4) `reviewer/metrics/brief_quality/**` остаётся без I/O, `eval/solve_task_metrics/` — ре-экспортом (guard-тест зелёный).

**Дополнительное требование пользователя (второй трек, вне текста тикета):** усилить в плагине `solve-task` обязательность штатной стартовой панели — три вопроса одной панелью (`Brief model tier` / `Interaction mode` / `Execution strategy`), без вольных переформулировок оркестратором. Причина: в этом самом прогоне панель была задана видоизменённо (два своих вопроса вместо трёх штатных), и текущий guard-тест такого не ловит.
