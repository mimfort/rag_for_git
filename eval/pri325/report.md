# PRI-325. Почему снизилась медиана покрытия ядра в PRI-324

[Карточка PRI-325](https://ru.yougile.com/team/686c049c8af8/#PRI-325)

Разбор от 25.11.2026 использует срез `5473e1246415bef521e95664819f2dab4c127ff2` и [архив PRI-324](../pri324/responses.json.gz). Обе секции восстанавливаются по Git-снимку задачи до исправления. Ссылка засчитывается при совпадении с полностью показанной и проверенной по Git строкой. Для каждой задачи складываются попадания и размеры ядра по повторам.

| Задача независимой выборки | Исходные фрагменты | Подбор фрагментов |
| --- | ---: | ---: |
| PRI-170 | 14 из 30 | 16 из 30 |
| PRI-202 | 4 из 22 | 5 из 22 |
| PRI-221 | 7 из 20 | 6 из 20 |
| Суммарное покрытие | 25 из 72 | 27 из 72 |

PRI-221 осталась срединной по покрытию, поэтому её изменение с 7 до 6 попаданий снизило медиану уровней с 35 до 30 %. Медиана парных изменений по задачам составила +4,55 п.п. Это две разные сводки по трём задачам.

В первом повторе исходный бриф PRI-221 сослался на `reviewer/mcp/session_serde.py:42` для объяснения восстановления политики. В брифе с подбором фрагментов ссылка на этот файл отсутствовала. Отрывок 42–56 совпадает побайтно в обеих секциях. Во втором повторе оба брифа ссылаются на строку 42. Полный запрос с подбором фрагментов, включая соседние задачи, имел одинаковый SHA-256 в обоих повторах. Таким образом, факт пропуска относится к отбору ссылок в брифе. Изменения в других файлах и соседних задачах остаются возможными источниками влияния в конкретном пакете.

В независимой выборке три приобретённых и одна потерянная ссылка пришлись на одинаковые отрывки. В одном случае исходный бриф PRI-170 назвал файл, но указал строку вне показанного диапазона. В основном корпусе восемь новых подтверждённых ссылок указывают на строки, отсутствовавшие в исходных отрывках. Две потерянные исходные координаты действительно вышли из новых отрывков. Это строка 117 реализации YouGile в PRI-215 и строка 384 проверки подключения GitHub в PRI-223. Доступность строки фиксируется отдельно от решения модели сослаться на файл.

В диагностической оценке для побайтно одинаковых секций одной задачи использовали исходный результат в обоих вариантах. Суммарное покрытие независимой выборки составило 25→26 из 72, медиана уровней осталась 35→30 %. Эта оценка сохраняет влияние соседних задач из исходных пакетных запусков.

## Четыре одиночные пары PRI-221

В каждом новом запросе была одна задача. Секции и постановка взяты из исходного сравнения. GPT-6 Luna с усилием `low` вызвана через `codex exec`, порядок вариантов чередовался. Все восемь брифов получены с первого запроса.

| Повтор | Исходный бриф | Подбор фрагмента |
| --- | ---: | ---: |
| 1 | 3 из 10 | 4 из 10 |
| 2 | 3 из 10 | 4 из 10 |
| 3 | 2 из 10 | 4 из 10 |
| 4 | 2 из 10 | 4 из 10 |

Одинаковая строка `session_serde.py:42` подтверждена в трёх исходных брифах и во всех четырёх брифах с подбором. Архивный пропуск в этих четырёх парах не воспроизвёлся. Число подтверждённых путей выросло с 22 до 41, из них размеченных с 17 до 24. Доля размеченных среди подтверждённых снизилась с 77,3 до 58,5 %. Одиночные пары относятся к одной задаче и приведены отдельно от оценки на пакетах.

## Воспроизведение

Из корня репозитория с зависимостями проекта и локальными Git-объектами снимков:

```bash
python -m eval.pri324.attribution --output /tmp/pri325-attribution.json
```

Команда сверяет контрольные суммы запросов, промпта, схемы и ответов. Ссылки проверяет тот же верификатор и по тем же Git-снимкам, что в PRI-324. Поле `retrospective.large` содержит обе медианы, изменения по задачам и чувствительность к одинаковым входам. Поле `retrospective.pairs` показывает исходную координату, её наличие в другом отрывке и ссылки из обоих брифов. Поле `singletons` содержит отдельные метрики восьми [сохранённых одиночных ответов](singleton-responses.json.gz). Для пересчёта модель и сеть не нужны.
