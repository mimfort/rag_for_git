## Поведение клиента

На этапе записи брифа сервер размечает подтверждённую по координатам запись с непригодным пояснением или непригодным путём как `invalid_reason` либо `invalid_path`. Остальные записи попадают в Markdown в исходном порядке. Клиент использует этот блок сразу и может повторить проверку полного списка с исправлениями. Если координаты были подтверждены, а все соответствующие записи оказались непригодны для вывода, сервер возвращает `invalid_format`. Нулевое число подтверждённых координат даёт обычный успешный пустой блок. Режим проверки координат `citations` сохраняет прежний ответ.
