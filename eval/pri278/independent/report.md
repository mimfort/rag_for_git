# PRI-283. Графовые зависимости на десяти дополнительных задачах

[Карточка PRI-283](https://ru.yougile.com/team/686c049c8af8/#PRI-283) · [Протокол](protocol.md) · [Разметка](../independent-corpus.json)

Контрольный корпус содержит десять задач rag_for_git, которых не было в исходных двадцати. Три задачи имеют ядро от десяти файлов. Проверены два механизма при прежнем лимите в 20 файлов. Поиск выполнен по Git-снимкам до исправления, на закреплённом replay-конвейере 2ae5721. Граф Tree-sitter построен отдельно для каждого снимка. Поисковые варианты используют один и тот же снимок и начальные кандидаты. Исторические сводки и подмешивание похожих задач не использовались.

Числа по брифам ниже относятся к версии `path-only-v1`. [Пересчёт PRI-293](../pri293.md) проверяет ссылки по полностью видимым строкам.

## Продвижение исходящего соседа

На подборе ни одна из квот от одного до четырёх соседей не сохранила среднюю и медиану покрытия ядра по всем задачам и крупным задачам одновременно. В независимом контроле проверена диагностическая квота в один файл, у которой была лучшая средняя дельта покрытия зависимостей на подборе (+1,7 процентного пункта).

На десяти задачах медиана покрытия ядра в секции кода осталась 69,0 %, а средняя попарная дельта составила −2,5 п.п. В брифах Luna медиана снизилась с 56,3 до 51,7 %. Медиана покрытия зависимостей в секции кода осталась 41,7 %. В брифах она осталась 33,3 %, со средней попарной дельтой −6,7 п.п. Квота не прошла критерий внедрения.

## Заполнение свободных мест

Проверяли до трёх дополнительных путей по исходящим рёбрам от гибридных чанков после первых 15. Добавления допускаются только при свободных местах в секции. Проверка подтверждает сохранение всех исходных путей. На старом корпусе покрытие ядра и зависимостей совпало. На независимом корпусе изменилось четыре секции кода. Для них запущены обе стороны сравнения с Luna. Для остальных шести по обоим условиям использован один и тот же сохранённый бриф с посимвольно одинаковой выдачей.

| Показатель на 10 задачах | Исходная выдача | Заполнение свободных мест |
|---|---:|---:|
| Медиана покрытия ядра в секции кода | 69,0 % | 69,0 % |
| Средняя попарная дельта покрытия ядра в секции кода | — | +0,9 п.п. |
| Медиана покрытия зависимостей в секции кода | 41,7 % | 50,0 % |
| Средняя попарная дельта покрытия зависимостей в секции кода | — | +3,3 п.п. |
| Медиана покрытия ядра в брифе | 57,8 % | 57,8 % |
| Средняя попарная дельта покрытия ядра в брифе | — | −0,9 п.п. |
| Медиана покрытия зависимостей в брифе | 33,3 % | 33,3 % |
| Средняя попарная дельта покрытия зависимостей в брифе | — | +5,0 п.п. |

У трёх крупных задач медиана ядра в секции кода выросла с 45,5 до 53,3 %, в брифах осталась 40,0 %. При этом одна крупная задача потеряла файл ядра в брифе после пересборки. Заполнение свободных мест прошло порог для секции кода и не прошло его для брифов. Производственное ранжирование сохранено.

На каждую различающуюся пару приходится по одному измерению Luna. Одного запуска недостаточно для отделения вариативности генерации от эффекта изменения контекста. Корпус включает задачи одного проекта. Измерение считает пути, а не информативность конкретных строк.

## Дополнительный пилот — дописать бриф без пересборки

На четырёх задачах с дополнительными фрагментами Luna получила сохранённый бриф и только новые фрагменты. Промпт просил предложить полезные новые ссылки, а исходный бриф сохранялся. Модель не предложила добавлений ни для одной из четырёх задач. Покрытие совпало с базовым. Вызов занял 25 376 входных и 132 выходных токена, поэтому этот дополнительный этап тоже не внедрён. Пилот использует те же четыре задачи и рассматривается как диагностический. [Ответы](append-batch.json) · [Метрики](append-results.json)

## Артефакты и воспроизведение

[Парные метрики и значения по задачам](results.json) · [Сырые пулы, тексты и ответы Luna](evidence.jsonl.gz)

```bash
.venv/bin/python -m eval.pri278.dependency_probe --evidence eval/pri278/pool_size/evidence.jsonl.gz --work /tmp/pri283-cal
.venv/bin/python -m eval.pri278.tail_deps_probe --evidence eval/pri278/pool_size/evidence.jsonl.gz --work /tmp/pri283-tail-cal
.venv/bin/python -m eval.pri278.replay --corpus eval/pri278/independent-corpus.json --hybrid-only --work /tmp/pri283-control
.venv/bin/python -m eval.pri278.dependency_probe --retrieval /tmp/pri283-control/all-30 --corpus eval/pri278/independent-corpus.json --work /tmp/pri283-control --quota 1
.venv/bin/python -m eval.pri278.tail_deps_probe --retrieval /tmp/pri283-control/all-30 --corpus eval/pri278/independent-corpus.json --work /tmp/pri283-control
```
