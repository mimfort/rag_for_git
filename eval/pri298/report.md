# PRI-298. Git-поиск в контексте и брифе solve-task

Дата прогона — 21.11.2026. Сравнение проведено на 20 исходных и 10 независимых исторических задачах PRI-278. Для каждой задачи использованы тот же базовый SHA, исходная постановка и зафиксированная гибридная секция кода. Контрольная секция совпала с архивом побайтно.

## Условия

| Режим | Дополнительный источник |
|---|---|
| Выключен | Сохранённый гибридный контекст |
| Широкий | BM25 по Markdown, SQL, YAML и TOML |
| Ограниченный | BM25 по Markdown из `plugin/skills/`, SQL, YAML и TOML |

Поиск читает обычные текстовые Git-блобы на базовом SHA с учётом исторического `paths.ignore`. Для двух лексических режимов исключены `eval/`, `docs/superpowers/` и тестовые пути. Параметры BM25 — k1 = 1,2 и b = 0,75. Путь учитывается дважды, термы запроса — по одному разу. При равной оценке порядок задан путём.

Во всех режимах действует общий лимит в 20 файлов с одним фрагментом до 975 исходных символов на файл, то есть до 19 500 исходных символов. Страховочный лимит после добавления заголовков и номеров строк составляет 29 250 символов. Найденные Git-фрагменты используют до трёх слотов внутри того же лимита. Каждый из 90 брифов сгенерирован с помощью GPT-6 Luna (`gpt-6-luna`, reasoning `low`) на одном промпте и с одинаковым порядком задач в пакетах по четыре. Модель получает постановку и секцию кода. Она возвращает краткую постановку и раздел Relevant code по методике PRI-278. Связанные задачи, сводки, тестовые примеры и прочие секции полного MCP-ответа в этот эксперимент не входят. Оценщик получает также эталонные пути.

Попадания считаются по парам «задача, обязательный путь», существующим на базовом SHA. Ссылка в брифе засчитывается, если в переданной секции видна вся указанная строка. Покрытие измеряется по итоговым ссылкам и отдельно по отобранным фрагментам. Замер задержки охватывает локальное чтение, ранжирование и построение отрывков Git. Гибридная часть взята из архива, поэтому сравнение задержек не является сквозным онлайн-замером.

Оба лексических режима использовали больше фактических символов внутри общего лимита. Для ограниченного режима суммарный вход вырос на 6,3 % по токенам модели. Ни одна секция не была усечена при отрисовке. Порядок широкого и ограниченного поиска чередовался по задачам. Замер Git исключает разрешение политики и гибридный поиск; p95 последнего в архиве составил 6 791 мс. Медиана времени одного модельного пакета составила 53,9, 61,8 и 59,9 с соответственно. Она зависит от очереди сервиса и используется как описательная величина.

Это один парный прогон на исторических задачах одного репозитория. Он оценивает покрытие ссылок в разделе Relevant code. Вариативность модели и успешность последующей реализации отдельно не измерялись.

## Воспроизведение

Входы PRI-278 находятся в исходном рабочем дереве. Для прогона нужен Git-клон с указанными в корпусах базовыми SHA. Артефакты запуска брифов пишутся во временный каталог. Суммы SHA-256 фиксируют версию входов.

| Файл относительно `eval/pri278/` | SHA-256 |
|---|---|
| `corpus.json` | `0144be2099d7edccd118ea06573f834104a477730ecbab465954087974d7b064` |
| `evidence.jsonl.gz` | `cc30d1d53510dc17968586a58a0d29098b1a30f0fc8760aa2bc63ed7c776ae6a` |
| `independent-corpus.json` | `e33836237dc2a5c22d391574dffbbf2f5925e5e28057b98e615c79a0bad25065` |
| `independent/evidence.jsonl.gz` | `97d6548bcb9dbd49fedddf24ffd9ab545321022a58138111fab0120a7681d2b3` |
| `briefs.py` | `8f336d428b8c734e01dffb3a93cc1910f59b81d039ed6255ba2b218647576b86` |

```bash
PRI278=/absolute/path/to/eval/pri278
WORK=$(mktemp -d)
export PYTHONPATH=.

python -m eval.pri298.replay prepare --pri278 "$PRI278" --work "$WORK"
python "$PRI278/briefs.py" --work "$WORK" --corpus "$WORK/corpus.json" \
  --input all-off all-wide all-narrow --workers 3
python -m eval.pri298.replay summarize --pri278 "$PRI278" --work "$WORK"
```

Исходные записи выбраны по `run=tune-30` и `run=holdout-30`, независимые — по `variant=all-30`. Для отчёта отобран один завершённый ответ без инструментальных вызовов на каждый пакет. Скрипт сверяет контексты при повторной подготовке и фиксирует их SHA-256 в результатах. Сохранённые модельные пакеты привязываются к режиму каталогом запуска и к задаче её ключом. Формат PRI-278 не сохраняет хеш полученного моделью входа внутри каждого ответа. Для быстрой проверки только выдачи Git к команде `summarize` можно добавить `--retrieval-only`.
