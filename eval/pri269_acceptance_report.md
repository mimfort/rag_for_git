## Найденные дефекты

### Д-1. Недоступность эмбеддера неотличима от прочих сбоев секции

**Условия замера.** 2026-08-28, до начала основного прогона. Хранилища **живы** (ParadeDB и Neo4j
отвечают, `reviewer check` зелёный). Внешний IP — датацентровый (`185.174.135.107`, Эстония, HZ
Hosting Ltd, AS59711), из-за чего Voyage отвечает `403 Forbidden`. Существенно: 403 приходит
HTML-страницей от фронтенда, **и без ключа тоже** — то есть режет посредник до аутентификации, а не
API по ключу.

**Наблюдение.** `prepare_task_context(repo="mimfort/rag_for_git", key="PRI-269", branch="dev")`
вернул:

```json
"gaps": [
  {"section": "task", "reason": "задачи нет в сторе", "cause": "unknown", "remedy": null},
  {"section": "subsystems", "reason": "сводки подсистем недоступны", "cause": "unknown", "remedy": null}
]
```

- `code`: «(ничего не найдено)», `test_exemplars`: «(ничего не найдено)»;
- `related.similar`: «(task search unavailable)»;
- `sync_board` (внутри `warm_board`): `enumerated: 126`, `changed: 3`, **`failed: 3`**, warnings —
  `embedder: APIError: HTTP code 403` (трижды) и `store links: task ID-323 not found`;
- задача PRI-269 в стор не попала, хотя на доске существует.

**Почему это дефект.** Классификация формально верна: Voyage не хранилище, и `reviewer start` его
действительно не чинит, поэтому `cause: unknown` / `remedy: null` — корректный выход из
`storage_health.is_storage_unavailable`. Но результат для пользователя тот же, ради устранения
которого делался PRI-268: контекст выпотрошен, причина не названа, а бриф собирается на
обеднённом входе, **внешне неотличимом от полного**. Пользователь видит «задачи нет в сторе» —
формулировку, указывающую на доску, тогда как настоящая причина в недоступности эмбеддера.

**Отношение к критерию 8.** Тот же класс: настоящая причина не доходит до пользователя. Критерий 8
прямо предусматривает выход «оставить как есть и завести отдельную задачу PRI со ссылкой на
замер» — по решению от 2026-08-28 приёмка правкой кода не расширяется.

Заведённая задача: _ещё не заведена (Task 7 плана)._
