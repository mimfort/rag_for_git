# PRI-330. Предупреждения в ссылках брифа solve-task

[Карточка PRI-330](https://ru.yougile.com/team/686c049c8af8/#PRI-330)

На `dbe578c` воспроизведён обычный PostToolUse для двух записей брифа. В первом запуске поиск вернул один из двух основных путей. Хук вставил предупреждение внутрь кодового фрагмента `path:line` и повторил его для координаты из пояснения. Во втором запуске поиск вернул оба основных пути. Оба предупреждения остались. В зафиксированном корпусе такой формат пояснений встретился в 16 брифах, всего в 20 строках с 25 дополнительными координатами.

Хук теперь проверяет часть строки до стандартного разделителя пояснения. Предупреждение находится после закрывающих бэктиков и снимается, когда путь появляется среди результатов. Существующий маркер внутри основной ссылки переносится наружу или удаляется при подтверждении пути. В пояснении удаляется только маркер, который старый хук вставил сразу после координаты. В исторических строках без разделителя по-прежнему проверяются все координаты. Секции с маркером серверной проверки сохраняются побайтно.

Проверка на двух записях воспроизводит одно предупреждение при первом поиске и ноль при повторном. Тесты проверяют CRLF, знаки препинания рядом с координатой, несколько ссылок в старой строке, повтор без изменений и побайтовое сохранение серверных секций.

python -m pytest -q tests/hooks tests/skills/test_solve_task_brief.py tests/mcp/test_brief_evidence.py
