# PRI-327. Исходная строка при замене фрагмента

[Карточка PRI-327 в YouGile](https://ru.yougile.com/team/686c049c8af8/#PRI-327)

На двух крупных задачах PRI-324 селектор убрал строку, на которую уже ссылался бриф. В PRI-215 он заменил начало `YougileBoard` со строкой 117 на `normalize_yougile`. Полный токен `YouGile` уже совпадал. Дополнительные части `gile` и `you` дали новой версии 0,672 балла. В PRI-223 конструктор `GitHubIssuesBoard.__init__` вытеснил `validate_connection` со строкой 384. Часть имени `init` дала 0,602 балла, хотя в постановке `reviewer init` обозначал команду CLI. В обоих случаях новый бриф одного из повторов пропустил соответствующий путь. Эти потери относятся к основному корпусу. Причина снижения медианы исходной независимой выборки рассматривается отдельно.

## Два окна в пределах исходного бюджета

При замене фрагмента экспериментальный вариант сохраняет первую непустую строку исходного окна и показывает начало выбранного окна. Оба заголовка входят в исходный лимит выбранного файла по символам и байтам UTF-8. Если в новом фрагменте исходная строка уже видна, дополнительный заголовок не требуется. Если оба окна не помещаются, сохраняется исходный фрагмент.

На всех 26 заменах в 13 архивных пакетах PRI-324 два окна поместились в лимит. В каждом остались первая исходная строка и начало выбранного окна. Указанные строки 117 и 384 снова видны, порядок файлов сохранился. Сверка обоих окон с историческим Git подтвердила номера и текст каждой показанной строки.

## Парные прогоны брифов

Парами сравнивали обычный экспериментальный селектор PRI-324 и вариант с двумя окнами. В двух повторах для каждой задачи отправляли отдельный запрос, порядок вариантов чередовали. Все 20 ответов получены с первого запроса. Использовали GPT-6 Luna, уровень low, неизменный промпт и разметку PRI-278. В подсчёт шли только пути с подтверждённой ссылкой на видимую строку исторического Git. Прогоны относятся к знакомому корпусу и одному репозиторию.

| Срез | Задач | Ядро PRI-324 → два окна | Медиана по задачам | Зависимости |
| --- | ---: | ---: | ---: | ---: |
| Крупные | 3 | 45/110 → 42/110 | 45,0 → 42,5 % | 5/14 → 5/14 |
| Обычные | 2 | 11/20 → 12/20 | 48,8 → 52,4 % | 4/10 → 4/10 |

Крупные задачи PRI-215, PRI-223 и PRI-257 дали 22/55 → 20/55 в первом повторе и 23/55 → 22/55 во втором. На обычных задачах PRI-241 и PRI-205 добавилось одно попадание. У двух окон восстановились исходные строки, а итоговый бриф на крупных задачах покрыл меньше файлов ядра. Селектор доступен для экспериментального сравнения.

## Проверка буквального совпадения

Отдельный вариант сохранял исходное окно, если в замене не было нового буквального совпадения с термином постановки. В качестве совпадений учитывались слова целиком и совпадающие части обычных имён в snake_case. Магические методы сами по себе не получали бонус за часть имени. Этот вариант вернул восемь исходных окон. Три крупные задачи исходного независимого корпуса по этому правилу получили те же пакеты, что и в PRI-324.

Пять из восьми запланированных пакетных пар завершились с первого запроса для обеих сторон. Из основного сравнения симметрично исключили три пары с дозапросами. В оставшихся парах с действительно изменившимися пакетами покрытие ядра крупных задач составило 30/76 → 27/76, обычных 5/10 → 0/10. На двух задачах с побайтово одинаковыми входами получилось 7/16 → 6/16. Результат показывает разброс ответов при одинаковом контексте и ограничивает вывод по малой выборке.

## Воспроизведение

`responses.json.gz` содержит модель, версию клиента, контрольные суммы входов и сохранённых ответов, группы задач, порядок повторов и статистику завершения. Из корня полного Git-клона с зависимостями проекта:

```sh
python -m eval.pri327.replay > /tmp/pri327-results.json
```

Команда заново строит окна на исходных снимках PRI-278 и проверяет ссылки штатным верификатором. Новых запросов к модели здесь нет.
