# PRI-324. Покрытие ядра в брифах крупных задач

[Карточка PRI-324](https://ru.yougile.com/team/686c049c8af8/#PRI-324)

Прогоны от 25.11.2026 используют код на `740f9e871e14010a05800153f7f930e0e34d2f60` и Git-снимки задач до исправления. Крупная задача имеет не менее десяти размеченных файлов ядра. В основной выборке пять таких задач, в независимой три. Обычные задачи и набор повторов указаны в протоколах. Разметка участвует только в оценке. Засчитанный путь требует ссылки на полностью показанную строку, прошедшую сверку с Git. В таблице числители и знаменатели суммируют пары «задача и файл» по повторам. У каждого варианта собственный парный контроль.

Архивный срез восьми крупных задач показал 39 из 120 файлов ядра в брифах. В выдаче 50 файлов ядра прошли сверку с Git. Из оставшихся 81 пропуска 47 возникли до финального отбора, 23 при отборе файлов, 10 при выборе ссылок и один при проверке координаты. Отдельная секция тестов в этих архивных пакетах отсутствовала.

| Изменение | Ядро крупных, контроль → вариант | Контрольные наблюдения |
| --- | ---: | --- |
| Слияние BM25 и ANN на уровне путей | 41/168 → 42/168 | На обычных задачах 10/16 → 6/16. |
| Выбор фрагмента внутри того же файла | **67/240 → 77/240** | На независимых задачах 25/72 → 27/72. У обычных задач 26/40 → 25/40. |
| Самопроверка по отдельным требованиям | 68/240 → 63/240 | У обычных задач 49/90 → 42/90. |
| Копирование номера видимой строки при составлении | 70/240 → 63/240 | У обычных задач 46/90 → 35/90. |
| Короткие идентификаторы строк | 74/240 → 62/240 | Два из 26 ожидаемых брифов пропущены. |
| Повышение effort на той же модели | 67/240 → 72/240 | Основной корпус 37/168 → 46/168, независимый 30/72 → 26/72. У обычных задач 22/45 → 21/45. |

При выборе фрагмента число и порядок путей совпали во всех парах. Первоначальный результат 66/240 → 76/240 включал три одиночных дозапроса в одном экспериментальном пакете. Во всех первоначальных парах без дозапросов покрытие выросло с 50 до 56 попаданий из 168. Обе стороны оставшейся пары запустили заново с тем же составом задач. Новая пара без дозапросов дала 17 и 21 попадание из 72. В отдельном контроле с одиночными запросами для тех же четырёх задач получены 21 и 24 попадания из 72. Основной результат 67/240 → 77/240 включает замену асимметричной пары. Она выполнена после проверки журнала.

После усреднения повторов медиана по трём независимым задачам снизилась с 35 до 30 %. Общая медиана восьми крупных задач сохранилась на уровне 31,25 %. Покрытие зависимостей выросло с 11 до 14 из 36, доля размеченных путей среди подтверждённых изменилась с 78 из 106 до 91 из 116. Длина секций крупных задач сократилась с 276 738 до 268 256 символов. Задержка и токены приведены отдельно в протоколе, поскольку длина секции не отражает полный расход клиента.

Повторная проверка отклонённой ссылки в прежнем фрагменте иногда возвращала нужный файл. Новое окно в Git также давало отдельные попадания, но требовало дополнительного входа и отдельного вызова. Смысловая проверка отклонила пример, где строка об обходе графа была предложена для пояснения о гибридном поиске. Доли по ссылкам зависят от такой проверки.

Эксперимент с выбором фрагмента включён в replay. Для включения в обычный solve-task требуется независимый прирост медианы и суммарного покрытия крупных задач при сохранении покрытия обычных задач и зависимостей. В текущей серии все пакеты происходят из одного репозитория. Выводы относятся к этим снимкам, модели GPT‑6 Luna и конкретным промптам.

## Воспроизведение

Для проверки сохранённых брифов нужны полный Git-клон с исходными объектами, Python-окружение проекта и временный каталог. Вариант выбора фрагмента и его контроль восстанавливаются из архивов и зафиксированных Git-снимков. Для команд подсчёта модель не вызывается.

```sh
replay_dir=$(mktemp -d)
cp eval/pri324/responses.json.gz "$replay_dir/"
python -m eval.pri324.replay score --work "$replay_dir"
python -m eval.pri324.effort
```

Для нового прогона выбора фрагмента используется команда `python -m eval.pri324.replay run --work <пустой-каталог>`. Протоколы двух остальных сравнений приведены в отчётах выше.
