# PRI-324. Инструкции по отбору ссылок для крупных задач

Два парных сравнения проведены 25.11.2026 на срезе `740f9e8`. В каждом использованы пять крупных задач из [корпуса PRI-278](../../pri278/corpus.json) и три крупные задачи из [корпуса PRI-283](../../pri278/independent-corpus.json). Крупной считается задача с ядром от десяти файлов. Для контроля взяты по четыре обычные задачи с наименьшими номерами PRI в каждом корпусе. Постановки взяты из корпусов, код прочитан из Git-снимков до решения. Секции кода взяты из архивов гибридного поиска `all-pool-30` и `all-30`, до 20 файлов на задачу.

Для каждого сравнения использованы два свежих повтора gpt-6-luna с усилием low в Codex CLI 0.170.0. Порядок подачи условий в пакетах развёрнут во втором повторе. Внутри пары совпадают байты постановок и кода, порядок файлов и схема структурированных ссылок. В промпте доступны только ключ, постановка и видимый код задачи. Экспертная разметка использована для выборки и оценки. В журнале завершённых действий в обоих экспериментах присутствовали только сообщения и рассуждения.

Контроль использует [структурированный промпт PRI-299](../../pri299/pilot.py). Первый вариант просит мысленно разложить постановку на изменения и критерии приёмки, затем сверить покрытие и добавить файл при наличии отдельного факта, нужного для задачи. Второй просит сначала найти строку, из которой следует причина добавить файл, и скопировать номер непосредственно с этой строки. Ход проверки в выходе не запрашивается. Полные промпты, контрольные суммы входов и ответы сохранены в архиве.

Ссылка проходит текущую проверку `BriefEvidence`, рендер и чтение итоговой секции. Дополнительно проверено совпадение текста и номеров всех показанных строк с Git-снимком штатным `check_brief_anchors`. Файл учитывается один раз на бриф. В числителе доли размеченных ссылок учитываются файлы ядра и зависимости из разметки. Остальные подтверждённые файлы могут быть полезны, поэтому доля служит приближением точности. Рекомендация требовала роста покрытия ядра крупных задач не менее чем на 5 п.п., одного направления по корпусам и повторам, сохранения покрытия ядра обычных задач и зависимостей, а также потери доли размеченных ссылок не более 5 п.п.

## Объединение двух базовых генераций

В каждом сравнении дополнительно объединили проверенные пути из двух независимых базовых генераций одной и той же задачи. Операция не использует разметку. На крупных задачах покрытие относительно первого повтора изменилось с 34/120 до 35/120 и с 35/120 до 38/120. В первом сравнении среди восьми новых путей размечены два. Во втором среди шести новых путей размечены четыре. Это диагностика верхней границы простого объединения путей двух полученных ответов. Она добавляет полный вызов модели и даёт менее 5 п.п. на обеих сериях.
