# PRI-315 Проверка повторяющихся строк в ссылках брифа

На исходной версии `42f3522` команда `reviewer brief-provenance` сравнивала текст по исходному номеру строки. В контрольном Git-репозитории поменяли местами две функции с одинаковой строкой `return 1`. Обе ссылки получили `unchanged`, хотя нужный текст в контексте функции переместился со строки 3 на 7 и со строки 7 на 3. После исправления команда указала оба новых номера. Если отличавшие функции соседние строки меняются и точного совпадения больше нет, команда возвращает `ambiguous`.

Если непустая строка встречается в изменившемся файле несколько раз хотя бы в одном из снимков, команда ищет точное совпадение отрывка с радиусом в одну или две строки вокруг ссылки. Отрывок должен содержать отличающийся непустой текст и встретиться ровно один раз в исходном и целевом файлах. Байтовое сравнение сохраняет отступы. Неоднозначный результат требует ручной сверки. Для одинаковых блобов содержимое отдельно не читается.

## Парный прогон

Использованы прежние зафиксированные ссылки и Git-снимки из [архива PRI-278](pri278/). Отдельная проверка читала `git show` и сверяла уникальность строки либо отрывка на фактическом предложенном номере. Исходный протокол, включая исключения и подбор целевого снимка, описан в [отчёте PRI-307](pri307/report.md).

| Целевой снимок | Ссылок | Уникальных переносов до | Уникальных переносов после | Неоднозначных до | Неоднозначных после |
| --- | ---: | ---: | ---: | ---: | ---: |
| Следующий снимок архива в пределах недели | 95 | 24 | 27 | 3 | 0 |
| Зафиксированный коммит реализации | 105 | 27 | 30 | 3 | 0 |

В обоих прогонах по соседним строкам уточнились три ссылки. В PRI-223 ссылка на `reviewer/entrypoints/cli.py:971` переместилась на 1223 и 1218. В PRI-225 ссылка на `reviewer/tasks/boards/base.py:26` переместилась на 29 в обоих снимках. В PRI-242 ссылка на `reviewer/entrypoints/cli.py:747` переместилась на 784 и 774. Остальные вердикты в этих прогонах совпали. Случай, когда прежний номер указывает на такой же текст другой функции, воспроизведён только в контролируемом Git-репозитории. Архивная оценка одного проекта подтверждает совпадение текста и окружающего отрывка.

## Воспроизведение

```bash
python -m pytest -q tests/entrypoints/test_brief_provenance.py -k repeated_lines
python -m eval.pri307.replay --output /tmp/pri315-replay.json
```

В JSON для каждого переноса указано основание `suggestion_proof`. `line` означает уникальную строку, `context` означает уникальный отрывок. Для сравнения с базовым алгоритмом выполните второй вызов на коммите `42f3522`.
